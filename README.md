# frugi-catalog

Публичный каталог сервисов для iOS-приложения **Frugi**: названия, тарифы и примерные цены с официальных страниц, ссылки на отмену подписок, акции.

- Файл: `catalog.json` → https://supermikeru.github.io/frugi-catalog/catalog.json
- Приложение только скачивает этот файл. **Пользовательских данных, ключей и персональной информации здесь нет** и не будет.
- Собирается скриптом `tools/build_catalog.py` в основном репозитории приложения.
